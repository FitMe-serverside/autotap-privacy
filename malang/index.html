goodmakers(이하 "회사")는 「잠금화면 말랑이」(이하 "앱")를 쓰는 분의 개인정보를 소중히 여깁니다. 이 방침은 앱이 어떤 정보를 다루는지, 어떻게 보호하는지 설명합니다.

1. 수집하는 개인정보

앱은 회원가입·로그인이 없고, 개인정보를 회사 서버나 다른 곳으로 보내지 않습니다. 광고, 분석 도구, 외부 추적 기능도 넣지 않았습니다.

2. 기기 안에서만 처리하는 정보

정보쓰는 곳저장 위치·기간
사용자가 고른 사진 또는 직접 찍은 셀카 ('내 얼굴 넣기')사진에서 얼굴 위치를 찾아 만화풍 그림으로 바꾼 뒤 장난감(말랑이·왁뿌볼·슬라임) 표면에 보여 줌원본 사진은 저장하지 않으며, 만화풍으로 바꾼 얼굴 그림 1장과 눈·입 위치만 앱 안 저장공간에 보관. 앱의 '얼굴 빼기'를 누르거나 앱을 지우면 바로 삭제
앱 설정 (고른 장난감, 진동·소리 켜기, 잠금화면 표시 설정 등)다음에 앱을 열 때 같은 설정 유지앱 안 저장공간, 앱 삭제 시 삭제

얼굴 찾기와 만화풍 변환은 안드로이드에 들어 있는 기능으로 휴대폰 안에서만 이루어지며, 인터넷으로 전송되지 않습니다. 회사는 이 사진이나 얼굴 그림을 볼 수 없습니다. 생체 인식(얼굴 인증)용으로 쓰지 않으며, 사람을 알아보거나 구별하는 데 쓰지 않습니다.

본인 얼굴이거나 사진 속 사람에게 허락을 받은 사진만 써 주세요. 다른 사람을 놀리거나 괴롭히는 용도로 쓰지 말아 주세요.

권한이유

알림, 포그라운드 서비스잠금화면 표시 기능이 켜져 있는 동안 화면 켜짐을 알아차리기 위해, 상태 알림 1개 표시
기기 부팅 시 실행휴대폰을 다시 켠 뒤에도 잠금화면 표시 기능을 이어서 쓰기 위해
진동장난감을 누를 때 손맛(진동) 효과

사진은 안드로이드 사진 선택기로 사용자가 고른 1장만 읽고, 셀카는 휴대폰 기본 카메라 앱으로 찍습니다. 앱은 사진첩 전체 읽기 권한이나 카메라 권한을 요청하지 않습니다.

4. 제3자 제공·위탁

회사는 어떤 개인정보도 제3자에게 제공하거나 처리를 맡기지 않습니다.

5. 아동의 개인정보

앱은 아동을 포함한 누구에게서도 개인정보를 수집하지 않습니다. 보호자는 언제든 '얼굴 빼기' 또는 앱 삭제로 기기 안의 얼굴 그림을 지울 수 있습니다.

6. 정보 삭제 방법

앱 안 [종류 고르기 → 내 얼굴 → 빼기]를 누르면 얼굴 그림이 삭제됩니다. 앱을 삭제하면 앱 안의 모든 데이터가 함께 삭제됩니다.

7. 문의

개인정보 처리, 열람 또는 삭제 관련 문의는 help@goodmakers.net으로 보내주세요. 이메일 문의에 포함된 정보는 답변 및 요청 처리에만 사용합니다.
